## Работа в фоне

В «Общих» есть блок «Работа в фоне»: уведомления, экономия батареи и, на MIUI и HyperOS, автозапуск; у каждой строки состояние и кнопка, которая открывает её системный экран. Те же три строки показывает `doctor`. На MIUI и HyperOS строка экономии батареи не называет состояния, пока приложения нет в списке исключений Android: система там ведёт свою настройку и этим списком распоряжается сама.
{% endif %}

## О приложении

«Версия приложения», «Версия движка Amnezia» - версия AmneziaWG в комплекте, «Тип сборки» - вариант сборки, если он задан, и «Репозиторий проекта» - ссылка на GitHub.

## Обновление

«Проверить обновления» спрашивает сервер релизов; найденная версия пишется рядом, «Скачать» качает её, «Установить» запускает установку, «Отмена» останавливает скачивание. «Проверять предварительные версии» включает в проверку бета-сборки. Проверка идёт и сама: о новой версии сообщает полоса «Доступно обновление» вверху окна{% if page.device == "windows" %} и оповещение в трее{% endif %}. Скачанный файл сверяется с опубликованной контрольной суммой.{% if page.device == "android" %} Установка APK требует разрешения ставить приложения из этого источника: система спросит его, и после ответа «Установить» нужно нажать ещё раз.{% endif %}

Как приложение обновляется - в разделе [Обновление](../install.ru.html#обновление) установки.
{% if page.device == "windows" %}

## Восстановление сети

Если после сбоя пропал интернет, кнопка «Восстановить» возвращает сетевым адаптерам прежние DNS-серверы; конфигурации и маршруты не меняются. Нужны права администратора: Windows спросит подтверждение.
{% endif %}

## Импорт / экспорт

Перенос конфигураций и списков маршрутизации на другое устройство одним файлом. «Экспорт…» открывает окно «Экспорт конфигураций и списков маршрутизации»: отметьте конфигурации и списки, у списка - отдельные правила, которые стоит перенести (правила на приложения этого компьютера на другом не нужны), затем «Скопировать содержимое», «Сохранить в файл…»{% if page.device == "android" %} или «Отправить…»{% endif %}. Файл несёт ключи конфигураций. «Импорт…» принимает такой файл: «Выбрать файл…» или вставка из буфера обмена, затем «При совпадении имён» - «Добавить как новое», «Заменить», «Пропустить» или «Объединить» - и «Сохранить». Файл, созданный более новой версией приложения, не читается: обновите приложение. Из консоли: `amneziageo bundle export --all --out <файл>` и `amneziageo bundle import --file <файл> [--policy new|replace|skip|merge]`.
