# Первая конфигурация

[English](first-config.md) | **Русский**

1. Откройте AmneziaGeo и импортируйте конфигурацию - файл `.conf`, QR-код или общий файл настроек.
2. Выберите список правил или полный туннель и подключитесь.

## Добавить конфигурацию

Пока конфигураций нет, на главном экране стоит кнопка «Добавить конфигурацию», потом - «Добавить» в разделе «Конфигурации». Способы: «Загрузить файл» - файл `.conf` или картинка с QR-кодом, «Вставить» - текст конфигурации, ссылка `vpn://` или адрес подписки из буфера обмена, «Создать вручную» - текст wg-quick в редакторе. Файл можно и перетащить в окно. Общий файл настроек с другого устройства - конфигурации и списки маршрутизации вместе - импортируется через «Импорт / экспорт» в разделе «Общие».

Каталог конфигураций - в разделе [Конфигурации](menu/configurations.ru.md).

## Выбрать маршрутизацию

Пока списка нет, весь трафик идёт через VPN. Список создаётся в разделе «Маршрутизация» кнопкой «Добавить»: выберите режим - «Только выбранное» или «Всё, кроме выбранного» - и шаблон, например «Недоступные сайты», и включите у списка «Используется». Сервер AmneziaGeo присылает свои списки сам: такой список появляется в разделе и, если сервер пометил его включённым по умолчанию, выбирается, пока не выбран другой.

{% include shot.html name="routing-new" alt="Новый список: режим VPN для приложений и выбор шаблона" caption="Новый список: режим и шаблон." %}

Режимы и списки - в разделе [Маршрутизация](menu/routing.ru.md).

## Подключиться

Нажмите кнопку посередине главного экрана. Пока соединение устанавливается, под кнопкой написано «Устанавливается соединение…», у подключённого туннеля - «Подключено»; неудачную попытку окно называет причиной: сервер не ответил, конфигурацию не удалось прочитать и так далее. После подключения окно можно закрыть: приложение остаётся в трее, а меню значка подключает, отключает и открывает окно.
