## Servers

The project runs no VPN servers of its own. Your traffic goes only to the servers you added yourself: with a configuration, a link, a QR code or a subscription.

A server sees which addresses you reach through the tunnel and when, and it hands out the settings, the routing lists and the DNS itself. A server can also offer updates of the program, see "Updates". Add only a server you trust: your own or one run by someone you know.

## Updates

The program asks GitHub (api.github.com) for new versions by itself and downloads them from there (github.com). The request carries nothing about you or your device. GitHub sees what any website sees: the address the request came from and the name of the program.

A server you added can offer an update server of its own. The program then checks for new versions and downloads them there instead of GitHub: on the server picked in "Connections" - "Update server", or, until you pick one, on the server recommended by your server. The files are taken only under a certificate the system trusts or the one your server named. The releases on such a server are put there by the one who runs it, not by the authors of the project: pick it only if you trust it as much as the server itself. After an update from it, "Where installed from" names that server. The update server sees the same as GitHub.

The other addresses the program reaches by itself are listed in "Privacy".
