# Installation

**English** | [Русский](install.ru.md)

Android 7.0 or newer.

Download `AmneziaGeo-<version>-android.apk` from the [Releases](https://github.com/bor-project/amneziageo/releases) page, or the three times smaller APK of your processor type (`-android-arm64.apk` suits most phones), and allow installation from that source when the system asks.
