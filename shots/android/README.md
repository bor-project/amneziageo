# Кадры приложения Android для сайта

Каждый кадр снимается одним заданием `frames/<имя>.py` на любом языке приложения. Задание не зависит от языка:
подписи оно берёт из строк клиента по ключу (`key=`), а не текстом.

## Где что

| Путь | Что |
|---|---|
| `frames.txt` | порядок съёмки и что на каждом кадре |
| `frames/<имя>.py` | задание кадра: где он стоит на сайте, что видно, в каком состоянии телефон, шаги |
| `languages.json` | языки: имя языка в списке «Язык интерфейса» приложения |
| `kit/ui.py` | adb, дерево окна, нажатия, строки клиента, маски, сохранение; `python kit/ui.py <язык> [шаг ...]` - пробы |
| `kit/stand.py` | подготовка телефона к языку и возврат после съёмки |
| `shoot.py` | съёмка |
| `local/` | настройки стенда, в git не идут: `stand.json` (серийный номер телефона, клон клиента), `mask.txt` (что размывать), `state.json` (как было до съёмки) |
| `out/<язык>/` | снятые кадры до просмотра, в git не идут |

На сайте кадр лежит в `docs/assets/img/android/<язык>/<имя>.png` и вставляется по имени:
`{% include shot.html name="<имя>" alt="..." caption="..." %}`. Размер вставки для Android шаблон ставит сам
(360x724); кадр без своего языка берётся английский.

## Стенд

- Телефон с приложением, adb по USB или беспроводной отладке (`adb mdns services`, `adb connect`). Экран открыт,
  телефон на зарядке и не гаснет.
- Нажатия: короткий `input tap` окно Avalonia не видит, нажатие с удержанием 150 мс (`input touchscreen swipe x y x y
  150`) доходит. На MIUI и HyperOS для этого включена «Отладка по USB (настройки безопасности)».
- Листание - колесом мыши (`input mouse scroll`, шаг 250 точек): медленный свайп пальцем, начатый на кнопке, нажимает
  её.
- Клавиатуру прячет Esc: «Назад», пока клавиатура открыта, закрывает и раздел. Новый список ставит курсор в имя, и
  клавиатура закрывает «Сохранить»: нажатие туда печатает в имя. Клавиатура исправляет `cidr` в `cider`: в поле
  набирается сам диапазон.
- Окно отдаёт дерево доступности (`uiautomator dump`): тип элемента, текст, подпись, границы. Задания ищут элементы
  по тексту строк клиента и нажимают в центр. Элемент, ушедший за край прокрутки, дерево показывает не там, где он
  нарисован: маски обрезаются по прокрутке. Многострочный текст размывается по строкам, найденным на снимке.
- Консоль приложения: broadcast `org.amneziageo.android/.CliReceiver`, `ui.cli("status")`. Команда идёт в процессе
  окна и ставит язык строк на системный (`CliRunner` зовёт `ApplyStartupCulture`), поэтому набор шлёт её с
  `--lang` языка окна.
- Всплывающее уведомление ложится поверх окна вместе с чужими сообщениями: `save` ждёт, пока SystemUI не
  покажет `mHeadsUpVisible=false`, и переснимает, если уведомление всплыло во время снимка.
- Свои конфигурации стенда: `Frankfurt` (подключается на время языка) и `Helsinki`, клиенты тестового сервера,
  заводятся до съёмки (`config import <имя> --file` из папки приложения на карте, файл после импорта удалить).
  `python shoot.py clean` их удаляет; клиентов на сервере удалить отдельно.
- Подготовка языка (`kit/stand.py`): записывает в `local/state.json`, как было (тема, язык, выбранная конфигурация и
  список, туннель), ставит светлую тему и язык, заводит свой список из текущего шаблона «Недоступные сайты»,
  выбирает список с именем шаблона на языке кадров, подключает `Frankfurt`. Возврат ставит всё, как было, и удаляет
  свой список. Списки владельца не меняются; на языке, где имени шаблона у владельца нет, их имена размываются.
- `local/stand.json`: `serial` (часть имени устройства в `adb devices`), `client` (клон клиента: строки берутся из
  его HEAD).
- `local/mask.txt`: регулярные выражения; элемент окна, чей текст под них подходит, размывается.

## Снять язык

1. `python shoot.py state` - что на телефоне сейчас.
2. `python shoot.py ru` - подготовка, все кадры из `frames.txt`, возврат. Один кадр: `python shoot.py ru general`.
   Оборвалось - `python shoot.py restore`. Телефон уже подготовлен - `python shoot.py try ru <кадр ...>`.
   Лист для просмотра: `python kit/sheet.py ru <кадр ...>` кладёт кадры рядом в `out/_sheet.png`.
3. Каждый кадр в `out/ru/` смотреть глазами: нет ли адресов, имён конфигураций владельца, ключей, QR настоящих
   конфигураций.
4. Годные кадры скопировать в `docs/assets/img/android/ru/`.

## Новый язык

1. В клиенте есть `Strings.<язык>.resx`, и язык есть в списке «Язык интерфейса».
2. Строка в `languages.json`: имя языка, как в списке приложения.
3. `python shoot.py <язык>`, просмотр, кадры в `docs/assets/img/android/<язык>/`.

## Новый кадр

1. Задание `frames/<имя>.py` по образцу: шапка (где, что видно, состояние), `run(ui)`: переход по ключам строк
   (`ui.open_section`, `ui.click(key=...)`), `ui.save("<имя>")`.
2. Строка в `frames.txt` и вставка на страницы Android.
