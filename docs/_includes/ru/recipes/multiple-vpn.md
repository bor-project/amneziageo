# {{ page.title }}

На Windows можно держать несколько VPN-туннелей одновременно. В настройках включите **Разрешить несколько VPN**, затем подключите нужные конфигурации серверов. Подключение следующего сервера добавляет туннель, сохраняя уже работающие подключения.

- Выберите **основной** сервер и порядок **резервных**. **Нейтральный** сервер находится вне этого порядка и обслуживает явно назначенный ему трафик.
- Для правила маршрутизации доступны **Авто**, **Лучший**, **Напрямую**, **Блок** или конкретный сервер. Можно задать и запасной маршрут для правила.
- Так раздельное туннелирование сочетается с несколькими подключениями: например, рабочая подсеть идёт через VPN офиса, выбранные сайты - через другой VPN, а остальной трафик в раздельном режиме остаётся прямым.

Сейчас этот режим доступен только на Windows. На Linux и Android используется одно активное VPN-подключение. Примеры команд - в [справочнике CLI](../cli.ru.html#несколько-vpn-одновременно).

## По шагам в окне

1. В разделе «Подключения» на вкладке «Туннель» включите «Разрешить несколько VPN».

   {% include shot.html name="connections-multi" alt="Вкладка «Туннель»: «Разрешить несколько VPN» включён, под ним интервал проверки, проверки перед переключением и порог" caption="Несколько VPN и переход правил между серверами." %}
2. В каталоге конфигураций включите «Используется» у каждого сервера, который должен быть поднят: каждый добавляет свой туннель, уже работающие остаются.
3. На главном экране в блоке «Серверы» нажмите место сервера и выберите «Основной», «Резервный 1», «Резервный 2» и дальше или «Нейтральный».

   {% include shot.html name="home-servers" alt="Главный экран в режиме нескольких VPN: блок «Серверы», два поднятых сервера и их места" caption="Блок «Серверы» на главном экране." %}
4. В редакторе списка у записи «Через VPN» выберите «Маршрут» - «Авто», «Лучший», «Напрямую», «Блок» или сервер - и «Запасной»: куда уйдёт трафик, когда выбранный сервер молчит.

   {% include shot.html name="routing-route" alt="Редактор списка в режиме нескольких VPN: раскрытая запись, в ней «Маршрут» и «Запасной»" caption="Маршрут и запасной у записей списка." %}

Переход правил между серверами настраивается под переключателем «Разрешить несколько VPN»: «Интервал проверки», «Проверок перед переключением», «Порог переключения». Когда сервер, на котором работал туннель, пропадает, туннель переходит на другой, и окно пишет об этом.
