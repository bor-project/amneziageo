# Кадры окна Linux для сайта

Каждый кадр снимается одним заданием `frames/<имя>.py` на любом языке приложения. Задание не зависит от языка:
подписи оно берёт из строк клиента по ключу (`key=`), а не текстом.

## Где что

| Путь | Что |
|---|---|
| `frames.txt` | порядок съёмки и что на каждом кадре |
| `frames/<имя>.py` | задание кадра: где он стоит на сайте, что видно, в каком состоянии стенд, шаги |
| `languages.json` | языки: имя языка в списке «Язык интерфейса» и локаль окна |
| `kit/stand.sh` | стенд на машине Linux: сборка, подъём и разборка пространств, окно, консоль |
| `kit/boot.sh` | что запускается в пространствах стенда: экран, оконный менеджер, агент |
| `kit/hook/` | помощник в процессе окна (`DOTNET_STARTUP_HOOKS`): дерево элементов по запросу |
| `kit/ui.py` | дерево окна, нажатия, строки клиента, маски, сохранение; `python3 kit/ui.py <язык> [шаг ...]` - пробы |
| `kit/stand.py` | подготовка стенда к языку и разборка |
| `kit/net.py` | сеть стенда до сервера конфигураций через ретранслятор |
| `kit/sheet.py` | листы кадров для просмотра |
| `shoot.py` | съёмка |
| `local/` | в git не идёт: `configs/<имя>.conf` (конфигурации стенда), `relay.json` (настоящие адреса серверов), `mask.txt` (что размывать) |
| `out/<язык>/` | снятые кадры до просмотра, в git не идут |

На сайте кадр лежит в `amneziageo-docs/client/assets/img/linux/<язык>/<имя>.png` и вставляется по имени:
`{% include shot.html name="<имя>" alt="..." caption="..." %}`. Кадр 984x752 - содержимое окна без рамки.

## Стенд

Набор копируется на машину Linux с рабочим столом в `/var/tmp/agdocs` и запускается там (`python3`, PIL, Xvfb,
openbox, xdotool, ImageMagick `import`, .NET SDK в `~/.dotnet`, клон клиента в `~/dev/amneziageo`).

- `kit/stand.sh build`: агент, консоль и окно из HEAD клона с версией `VERSION` (по умолчанию 1.10.8.0) и адресом
  обновлений пакета; вывод и obj в `/var/tmp/agdocs/art`, дерево клона не меняется. Там же помощник окна.
- Стенд в своих пространствах (`unshare -m -n`): свой `/tmp` (сокет агента), свой `/run` (системная шина, сеанс
  пользователя и сокеты движка хоста не видны), свой sysfs (агент видит свои интерфейсы, cgroup хоста ему не
  достаётся), `/etc/resolv.conf` закрыт своим файлом. Без этого агент стенда тронул бы хост: он пишет
  `/etc/resolv.conf`, зовёт systemd-resolved по шине и переносит процессы приложений из правил в свою cgroup.
  Агент и служба на самой машине не трогаются.
- Библиотека стенда (`run/data`) привязана поверх `/var/lib/amneziageo` только внутри стенда: в диагностике виден
  путь пакета, библиотека машины не трогается. Без привязки стенд не поднимается.
- Экран `:97` (Xvfb 1600x1000), окно 984x752. Окна Linux не отдают дерево доступности: его отдаёт помощник
  `kit/hook` по запросу в файле `run/hook/req`. Нажатия и ввод - xdotool, снимок - `import -window`.
- Сеть: у пространства стенда нет выхода наружу. `kit/net.py` ставит интерфейс-заглушку с адресами Endpoint
  конфигураций стенда (203.0.113.10, .11) и ретранслятор UDP до настоящих серверов, служебный порт сервера
  (`# AmneziaGeo Services`, TCP: сервер сам предлагает WebSocket, замер скорости, подписку) передаётся так же;
  интернет у стенда только через туннель. Конфигурации стенда заводятся так: текст конфигурации в stdin
  `python3 kit/net.py add Frankfurt 203.0.113.10:51820`, то же для `Helsinki` (203.0.113.11).
- Подготовка языка (`kit/stand.py`): чистая библиотека, импорт `Frankfurt` и `Helsinki`, подключение без списка,
  `geo update` и ожидание дат у всех источников (через туннель около 20 минут), светлая тема и язык окна, свой список
  из шаблона «Недоступные сайты», подключение `Frankfurt`. Базы качаются только до первого списка: со списком DNS
  агента для имён вне списка идёт к системному резолверу напрямую, а напрямую у стенда сети нет.
- `--keep` (`shoot.py <язык> --keep`, `shoot.py setup <язык> --keep`): стенд на библиотеке и настройках окна прошлого
  подъёма, без импорта и загрузки баз: ставятся язык окна и список с именем шаблона на этом языке, списки на других
  языках удаляются. Так переснимаются отдельные кадры.
- Под нагрузкой через ретранслятор туннель теряет пакеты: главный экран снимается без нагрузки, каталог ждёт, пока
  потери в карточке не станут 0%. Проба идёт путём «Туннель» (при «Авто» замер отдачи к speed.cloudflare.com уходит
  напрямую и не стартует) и повторяется до записи «ok» во всех проверках.
- `local/mask.txt`: регулярные выражения; элемент окна, чей текст под них подходит, размывается.

## Снять язык

1. `python3 shoot.py ru` - подготовка, все кадры из `frames.txt`, разборка. Один кадр: `python3 shoot.py ru general`.
   Стенд уже подготовлен - `python3 shoot.py try ru <кадр ...>`. Лист для просмотра: `python3 kit/sheet.py ru`.
2. Каждый кадр в `out/ru/` смотреть глазами: нет ли адресов серверов, ключей, QR настоящих конфигураций.
3. Годные кадры скопировать в `amneziageo-docs/client/assets/img/linux/ru/`.
4. После всех языков: `python3 shoot.py clean` (библиотека с ключами), удалить `local/configs` и клиентов на сервере.

## Новый язык

1. В клиенте есть `Strings.<язык>.resx`, и язык есть в списке «Язык интерфейса»; в системе есть его локаль.
2. Строка в `languages.json`: имя языка, как в списке приложения, и локаль.
3. `python3 shoot.py <язык>`, просмотр, кадры в `amneziageo-docs/client/assets/img/linux/<язык>/`.

## Новый кадр

1. Задание `frames/<имя>.py` по образцу: шапка (где, что видно, состояние), `run(ui)`: переход по ключам строк
   (`ui.open_section`, `ui.click(key=...)`), `ui.save("<имя>")`.
2. Строка в `frames.txt` и вставка на страницы Linux.
