# Кадры окна Windows для сайта

Каждый кадр снимается одним заданием `frames/<имя>.ps1` на любом языке клиента. Задание не зависит от языка:
подписи кнопок оно берёт из строк клиента по ключу (`T`, `Click-Key`, `Open-Section`), а не текстом.

## Где что

| Путь | Что |
|---|---|
| `frames.txt` | порядок съёмки и что на каждом кадре |
| `frames/<имя>.ps1` | задание кадра: где он стоит на сайте, что видно, в каком состоянии стенд, шаги |
| `languages.psd1` | языки: формат дат и чисел, имя языка в списке «Язык интерфейса» клиента |
| `kit/` | исполнитель на стенде и общие функции: перезапуск окна, нажатия, маски, сохранение |
| `kit/setup.ps1`, `kit/restore.ps1` | подготовка стенда к языку и возврат после съёмки |
| `shoot.sh`, `do.sh` | съёмка с машины разработчика по ssh |
| `local/` | настройки стенда, в git не идут: `stand.env` (адрес стенда, клон клиента), `mask.txt` (что размывать) |
| `out/<язык>/` | снятые кадры до просмотра, в git не идут |

На сайте кадр лежит в `amneziageo-docs/client/assets/img/windows/<язык>/<имя>.png` и вставляется по имени:
`{% include shot.html name="<имя>" alt="..." caption="..." %}`. Шаблон берёт кадр на языке страницы, без него -
английский; проверка сайта (`check_site.py`) считает такие кадры.

## Стенд

- Windows 10 или 11 с установленным клиентом в `C:\Program Files\AmneziaGeo`, ssh по ключу, вход в консоль под
  тем же пользователем: окно снимается только в сессии рабочего стола.
- Конфигурации с выдуманными именами, одна поднята; список маршрутизации из шаблона «Недоступные сайты». На стенде кадров:
  Frankfurt (поднята), Amsterdam и Helsinki (второй интерфейс того же тестового сервера, для «Несколько VPN»).
- `local/stand.env`: `AG_HOST=<пользователь>@<адрес>`, `AG_CLIENT=<клон клиента>` (строки берутся из его HEAD).
- `local/mask.txt`: имена и адреса стенда, которые размываются на кадрах.
- Установщик той же версии, что установлена, в `Downloads` пользователя (кадры `install-*`). Установщик до AG-415
  говорит на языке Windows, а не приложения (на стенде 16.10 он шёл за форматом региона: ru-RU давал русский при
  английском списке языков), и кадры `install-*` на другом языке пропускаются. Установщик с AG-415 берёт язык из
  настройки приложения: такую сборку положить в `local/installer/`, `shoot.sh` увезёт её в `agshots\installer`, и
  кадры `install-*` снимутся на любом языке.
- Кадры рецепта «Несколько VPN» с блоком «Серверы» и «Маршрутом» правила требуют двух поднятых туннелей к разным
  серверам: с одним туннелем окно их не показывает.

## Снять язык

1. `./shoot.sh push` - набор ложится в `%TEMP%\agshots` пользователя стенда.
2. Исполнитель запускает владелец в консоли стенда: Win+R, `wscript "%TEMP%\agshots\launch.vbs"`. Он живёт до
   выхода из сеанса или до `./shoot.sh clean`.
3. `./shoot.sh ru` - подготовка (формат, светлая тема, язык окна, имя списка на языке), все кадры из `frames.txt`,
   возврат стенда. Один кадр: `./shoot.sh ru general`.
4. Каждый кадр в `out/ru/` смотреть глазами: нет ли адресов, имени пользователя, ключей, QR настоящих конфигураций.
5. Годные кадры скопировать в `amneziageo-docs/client/assets/img/windows/ru/`.
6. `./shoot.sh clean` - убрать исполнитель и набор со стенда.

## Новый язык

1. В клиенте есть `Strings.<язык>.resx`, и язык есть в списке «Язык интерфейса».
2. Строка в `languages.psd1`: культура и имя языка, как в списке клиента.
3. `./shoot.sh <язык>`, просмотр, кадры в `amneziageo-docs/client/assets/img/windows/<язык>/`.
4. На страницах языка те же вставки `shot.html` по имени, подписи `alt` и `caption` на этом языке.

## Новый кадр

1. Задание `frames/<имя>.ps1` по образцу: первая строка `Reset-Ui`, переход по ключам строк, сохранение
   `Save-Masked` (размыть стенд и все адреса) или `Save-LineMasked` (журналы: размыть только строки со стендом).
2. Текст в задании только по ключам: подписи кнопок, вкладок и данные, которые зависят от языка (имя списка из
   шаблона). Пункты списков, которые клиент не переводит (`routes`, `probe`), и ввод (`netflix`) - как есть.
3. Строка в `frames.txt` и вставка на страницы.
