# Установка

[English](install.md) | **Русский**

Нужен Android 7.0 или новее.

Скачайте `AmneziaGeo-<версия>-android.apk` со страницы [Releases](https://github.com/bor-project/amneziageo/releases) или втрое меньший APK под свой процессор (большинству телефонов подходит `-android-arm64.apk`) и разрешите установку из этого источника, когда система спросит.

Дальше - [первая конфигурация](first-config.ru.md).

## Android TV

На телевизоре ставится тот же APK; разница в том, как его туда доставить. Скопируйте файл на флешку и откройте файловым менеджером телевизора, либо поставьте с компьютера: включите на телевизоре отладку по сети в настройках для разработчиков и выполните `adb install AmneziaGeo-<версия>-android-arm64.apk`. Разрешение на установку из этого источника телевизор спросит так же, как телефон. Приложение появляется среди остальных на главном экране Android TV; по нему ходит пульт: стрелки переводят выделение, «OK» нажимает.

## Обновление

Обновления приложение проверяет само, скачивает APK под свой процессор и ставит его с вашего согласия. Кнопки - в разделе [Общие](menu/general.ru.md#обновление).

## Удаление

Удаляется как любое приложение: долгое нажатие на значок и «Удалить» либо «Настройки» - «Приложения» - AmneziaGeo. Конфигурации, списки и гео-базы хранятся внутри приложения и удаляются вместе с ним; чтобы перенести их на другое устройство, сначала сделайте экспорт в разделе [Общие](menu/general.ru.md#импорт--экспорт).
